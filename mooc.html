SQL for Business Data Analytics: MOOC Resource Hub

This page curates free video-based and online learning resources for students who want to strengthen SQL skills for business data analytics. The selected resources support topics such as relational databases, SELECT queries, filtering, joins, aggregation, subqueries, CTEs, window functions, PostgreSQL, and analytics-oriented SQL practice.

Beginner to intermediate Business analytics focus YouTube + free online courses Self-paced learning
How students should use this page: Start with one beginner video course, practice queries using an interactive platform, then move to joins, aggregation, CTEs, and window functions. Students do not need to complete every resource; the goal is to build fluency through repeated practice.

Suggested Learning Path

1. Setup and basics Learn what relational databases are and how SQL retrieves data.
2. Core querying Practice SELECT, WHERE, ORDER BY, LIMIT, and basic functions.
3. Business analytics queries Learn joins, GROUP BY, HAVING, subqueries, and CTEs.
4. Advanced analysis Study window functions, PostgreSQL, and project-based SQL analysis.
