Database and Python Tools

Tools for SQL and Business Data Analytics

This page introduces the main database systems, SQL clients, and Python libraries students may encounter in business analytics. For MIS 443, PostgreSQL is the primary database, with Python/Jupyter used for analysis and reporting workflows.

Primary DBMS

PostgreSQL

PostgreSQL is the main database system for this course and for the book code. Students use it to restore the sqlda database, run SQL exercises, practice joins, CTEs, window functions, JSONB, and connect to Python.

Recommended Setup

What students should install for MIS 443

Minimum setup

  1. Install PostgreSQL.
  2. Install pgAdmin or use psql.
  3. Restore the sqlda database from data.dump.
  4. Install Python and Jupyter Notebook or Anaconda.
  5. Install pandas, SQLAlchemy, and psycopg or psycopg2.
pip install pandas sqlalchemy psycopg psycopg2-binary jupyter
