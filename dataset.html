1. What is this dataset about?

The sqlda database simulates a business analytics environment for a vehicle sales company. It contains customer profiles, sales transactions, products, dealerships, salespeople, marketing email interactions, geographic information, public transportation information by ZIP code, and survey feedback.

Students will use this dataset to practice relational database concepts, data exploration, filtering, joins, aggregation, window functions, JSON processing, text processing, date/time analysis, geospatial analysis, and basic analytics using SQL.

6. Starter exploration questions for students

  1. Which tables represent business entities, and which tables represent business events?
  2. Which columns can be used to join customers, sales, and products?
  3. Which table can help analyze email campaign performance?
  4. Which tables contain geographic or location-related information?
  5. Why might customer_sales be useful for learning JSONB even though relational tables already exist?

7. Other popular datasets for SQL practice

Besides the main sqlda database, students can use the following public/sample datasets for additional SQL practice. Always check licensing, data quality, and whether the dataset is suitable for the intended learning goal.

Dvdrental
PostgreSQL sample database for joins, customers, inventory, rentals, and payments. Postgres Sample DBs
Collection of PostgreSQL-ready sample databases including Northwind and Pagila. Northwind PostgreSQL
Classic business database with customers, orders, products, suppliers, and employees. Pagila
PostgreSQL port of Sakila, useful for rental, inventory, customer, and payment analysis. Kaggle Datasets
Large collection of public datasets for analytics projects; licensing varies by dataset. UCI Machine Learning Repository
Public datasets for data preparation, analytics, and modeling practice.
